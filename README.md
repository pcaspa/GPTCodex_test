# GPTCodex_test

This repository now contains a simple clone of the classic Space Invaders arcade
game implemented with [pygame](https://www.pygame.org/).

## Requirements

* Python 3.9+
* `pygame` (install with `pip install pygame`)

## Running the game

```bash
python space_invaders.py
```

Use the arrow keys (or `A`/`D`) to move, press space to fire, and survive as
long as you can. When you lose all lives or aliens reach the cannon, the game
overlay will prompt you to press Enter to play again.
